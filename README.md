# pca-process-monitor
Python library for PCA-based process monitoring — continuous and batch processes. Includes NIPALS, T², Q, contribution plots, and AI-assisted interpretation.

## Injection moulding project

The development prototype adds a client brief, machine candidates and a parametric 3D shell preview with thickness variants and OBJ export. Mold design, STEP import, process simulation and cost optimisation are planned modules.
