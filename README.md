# pca-process-monitor
Python library for PCA-based process monitoring — continuous and batch processes. Includes NIPALS, T², Q, contribution plots, and AI-assisted interpretation.

## Injection moulding project

Mould Studio adds a CAD-style workspace, parametric text commands, OBJ/STL viewing, photo references, a client brief and machine candidates. The offline demo includes a parameterised shell with thickness variants and OBJ export. AI agents, automatic photo reconstruction, mold design, STEP import, process simulation and cost optimisation are planned modules.
