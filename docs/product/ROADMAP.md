The first demonstrated result uses declared synthetic inputs and includes startup/drain: two cavities ~805.7 parts/h, four ~752.2 with a four-slot belt/12-part boxes. Changing the four-cavity boxes to 48 parts raises output to ~954.0 parts/h. A faster downstream counterexample reverses the baseline ranking. This proves the implemented resource coupling, not real production performance or polymer physics.

Next: verify the branch in the owner's private Codespace, calibrate a real press/robot/packaging cycle and add explicit EOAT/extraction/orientation/geometric checks. Keep simulation manual-first and provider-independent. CAE/Timestral/desktop/new hosting are not prerequisites for this increment.
