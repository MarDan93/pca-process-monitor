## Implemented boundaries

`server/app/process.py` is a bounded deterministic L0 scheduler with explicit assumptions and completion-time inventory transfers. `process_runs` is an additive SQLite table; approved process configuration joins project snapshots and survives unrelated commercial/asset edits. Run writes do not mutate project revision. A project edit conservatively marks older runs outdated. Latest runs survive service replacement; no full run history UI or independent backup/recovery is implemented.

`prototype/server-ai.mjs` is a fixed, short-lived Node CPU inference process with the existing model/revision and SHA-256 gate. Python limits concurrency to one model job, enforces a timeout and kills its owned process on disconnect. Inference is cache-only after explicit setup, which may download pinned files. The LLM has no shell/CAD/HTTP tools. Text proposals pass strict schemas and the same expiring approval ledger as manual edits. A numeric-string proposal was observed and rejected during development; prompt examples improved the tested extraction. This is narrow successful inference evidence, not comprehensive accuracy or injection-resistance validation.

The browser still renders 3D; remote CPU inference does not remove the need for a bounded scene on the owner's laptop. Imported product geometry is retained, but functional cell envelopes and linear paths are illustrative and are not checked for clearance, strokes or collisions. No detailed melting, drying moisture, filling/thermal fields, quality, costs, cooling-circuit design, STEP or integrated PCA/PLS is delivered.
